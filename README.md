# Airbnb Clone - Full Stack Web Application

A full-stack Airbnb-style accommodation booking application built using Node.js, Express.js, MongoDB, React.js, and modern web technologies.

## Features

- User registration and login
- Session-based authentication
- Host and Guest roles
- Hosts can add and manage properties
- Browse available homes
- View property details
- Add and remove favourite properties
- Property booking functionality
- Image upload support
- Responsive user interface

## Tech Stack

### Frontend
- React.js
- Vite
- JavaScript
- CSS
- Axios

### Backend
- Node.js
- Express.js
- MongoDB
- Mongoose
- Multer
- Express Session

## Installation

### 1. Clone the repository

git clone https://github.com/yogitabeniwal83/Airbnb-Clone-FullStack.git

### 2. Install Backend dependencies

cd Backend
npm install

### 3. Install Frontend dependencies

cd ../Frontend
npm install

### 4. Configure environment variables

Create the required `.env` file for database connection and application secrets.

Do not commit the `.env` file to GitHub.

### 5. Start Backend

cd Backend
npm run dev

### 6. Start Frontend

cd Frontend
npm run dev
